# CeneoWebScraper

Ceneo Web Scraper is an application that analyzes product reviews from the Ceneo.pl website. The user provides a Product ID, and the tool retrieves detailed review information, presenting it in a user-friendly format with generated charts.

## Installation and Setup

### 1. Create Virtual Environment
      python -m venv .venv
### 2. Activate Virtual Environment
 Windows

     source .venv\Scripts\activate

Linux/Mac

      source .venv/bin/activate

### 3. Install Dependencies

      pip install -r requirements.txt

### 4. Run the application

      flask run
